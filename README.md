# 🛡️ Cyber Incident Management System

## 📌 Project Overview

The **Cyber Incident Management System** is a web-based application developed to record, manage, track, and monitor cybersecurity incidents through a centralized platform.

The main purpose of this project is to simplify incident management by maintaining incident-related information in an organized manner. It helps users manage cybersecurity incidents efficiently and maintain records for future reference.

## 🎯 Project Objectives

- To provide a centralized platform for managing cyber incidents.
- To record and maintain incident details.
- To simplify the process of tracking cybersecurity incidents.
- To organize incident-related information in a database.
- To improve the efficiency of incident management.

## ✨ Features

- Web-based user interface.
- Cyber incident record management.
- Database connectivity.
- Organized incident information storage.
- Easy access to the application through a web browser.

## 🚀 Installation and Setup

**Step 1: Clone the Repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Open the Project Folder**

```bash
cd cyber-incident-app
```

**Step 3: Install Dependencies**

```bash
npm install
```

**Step 4: Configure Environment Variables**

Create a `.env` file in the root directory and configure your database connection:

```env
DB_SERVER=localhost
DB_NAME=your_database_name
DB_USER=your_database_username
DB_PASSWORD=your_database_password
PORT=3000
```

Replace the database details with your actual SQL Server configuration.

**Step 5: Run the Application**

```bash
node server.js
```

**Step 6: Open the Application**

Open your browser and visit:

```text
http://localhost:3000
```

## 🗄️ Database Configuration

This project uses Microsoft SQL Server for database management.

Make sure that:

- SQL Server is installed and running.
- The required database has been created.
- Database credentials are configured correctly in the `.env` file.
